# 🏫 Sistema Escolar

Sistema web desenvolvido para auxiliar na gestão de unidades escolares, usuários, escolas e relatórios.

## 📌 Sobre o Projeto

O Sistema Escolar é uma aplicação front-end desenvolvida com HTML, CSS e JavaScript.

O projeto permite realizar o gerenciamento básico de usuários e escolas, além de apresentar informações em um painel administrativo.

## 🚀 Funcionalidades

- 🔐 Tela de login
- 📊 Dashboard administrativo
- 👥 Cadastro e gerenciamento de usuários
- 🏫 Cadastro e gerenciamento de escolas
- 🔎 Pesquisa de usuários e escolas
- 📈 Relatórios do sistema
- ⚙️ Configurações do sistema
- 💾 Armazenamento de dados utilizando LocalStorage
- 🎨 Interface administrativa responsiva

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
- Visual Studio Code
